# 🔐 Generate Random Password

A simple and responsive **Random Password Generator** built using **HTML, CSS, and JavaScript**.

This project generates a random password containing **uppercase letters, lowercase letters, numbers, and special characters**. It also provides a **Copy Password** feature so users can easily copy the generated password.

## 🚀 Features

* 🔑 Generate a random password
* 🔠 Includes uppercase letters
* 🔡 Includes lowercase letters
* 🔢 Includes numbers
* 🔣 Includes special characters
* 📋 Copy generated password to clipboard
* ⚡ Simple and fast user interface
* 📱 Clean and responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript** – Password generation and copy functionality

## ⚙️ How It Works

The application uses JavaScript to create a password from different character sets:

* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

The generated password has a default length of **12 characters** and contains at least one character from each of the four character categories.

The user can click **Generate Password** to create a new password.

The **Copy** button copies the generated password to the clipboard.

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/yashwant427/Generate-Random-Password.git
```

2. Open the project folder:

```bash

```

3. Open `index.html` in your browser.
